# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.4.0]

### Added
- **Tenebris Light** colour theme: a dimmer light variant with a faint lavender tint on the UI and the same lavender accent, darkened for contrast.
- Light variants of every file icon, used automatically with light colour themes.
- Bold styling for word-like keywords (`and`, `or`, `not`, `from`, `struct`, `enum`, `sizeof`) and language constants (`True`, `None`, `NULL`, ...) in both themes.

## [0.3.5]

### Added
- Marketplace icon.
- Changelog, CI and release automation.

### Changed
- Rewrote the README to match the bundled features.
- Display name is now "Tenebris for VS Code".
- The extension no longer forces `workbench.colorTheme` or `workbench.iconTheme`.

## [0.3.4]

### Changed
- Python icon is now a filled, interlocking two-snake design.

### Added
- Dedicated icons for C, C++, TypeScript, JavaScript, R, Java, Go, Lua, Swift,
  Kotlin, Ruby, PHP, Scala, Dart, Haskell, Julia, Zig, shell, R Markdown and
  Objective-C.

## [0.3.3]

### Added
- Six-colour nested bracket highlighting (lavender, sand, sage, blue, rose, silver).

## [0.3.2]

### Added
- Bracket pair colourization defaults.
